# Weather App

A modern weather application built with React, TypeScript, and TanStack Query. Get real-time weather data, manage favorites, and track search history.

## 🛠️ Tech Stack

- React 18 + TypeScript
- TanStack Query
- Shadcn UI + Tailwind CSS
- Recharts
- OpenWeatherMap API

## ✨ Features

- Real-time weather data with geolocation
- Hourly forecasts and 5-day predictions
- Favorite cities management
- City search with history

## 🚀 Getting Started

**Step 1: Clone and install**

```bash
git clone <repo-url>
npm install
```

**Step 2: Add your API key in `.env`**

```env
VITE_OPENWEATHER_API_KEY=your_api_key_here
```

**Step 3: Run the app**

```bash
npm run dev
```
